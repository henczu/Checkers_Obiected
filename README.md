# Checkers Game ♟️

A classic Checkers (Warcaby) game implemented entirely in Java, focusing on Object-Oriented Programming (OOP) principles. 

This project was built to practice clean architecture, logical separation of components (Board, Pieces, Game State), and object-oriented design patterns.

## 🎮 Features
- Standard checkers rules and piece movements.
- Object-oriented design ensuring code maintainability.
- Clear separation between game logic and representation.

## 🚀 Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher.

### How to run
1. Clone the repository:
   ```bash
   git clone https://github.com/henczu/Checkers_Obiected.git
   ```
2. Navigate to the source folder:
   ```bash
   cd Checkers_Obiected/src
   ```
3. Compile the Java files (assuming `Main.java` is your entry point - adjust if necessary):
   ```bash
   javac Main.java
   ```
4. Run the application:
   ```bash
   java Main
   ```
